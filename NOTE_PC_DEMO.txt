PC DE DEMO - invite de commande (cmd)

1re fois seulement, depuis le dossier du projet (bornes-projet) :
  (backend\.env est deja dans le repo, rien a creer)
  cd backend && npm install && npx prisma generate && cd ..
  cd app-borne && npm install && cd ..
  cd app-admin && npm install && cd ..

1re fois seulement, cmd en administrateur (pare-feu) :
  netsh advfirewall firewall add rule name="Bornes 3000" dir=in action=allow protocol=TCP localport=3000
  netsh advfirewall firewall add rule name="Bornes 5173" dir=in action=allow protocol=TCP localport=5173

A chaque demo, depuis le dossier du projet (bornes-projet) :
  start "Backend" cmd /k "cd backend && npm start" && start "Borne" cmd /k "cd app-borne && npm run dev -- --host" && start "Admin" cmd /k "cd app-admin && npm run dev"

IP du PC (pour le bot et les tablettes) :
  ipconfig      -> "Adresse IPv4"

Acces :
  Backend : http://localhost:3000/       ("botConnecte": true = bot relie)
  Borne   : http://localhost:5173/       (tablette : http://IP:5173/)
  Admin   : http://localhost:5174/connexion   (admin@bowling.local)
  (si les ports different : l'URL exacte s'affiche dans les fenetres Borne / Admin)
