PC CONQUEROR - invite de commande (cmd ou PowerShell)

1re fois seulement, depuis le dossier bornes-projet\bot :
  python -m venv venv
  venv\Scripts\python.exe -m pip install -r requirements.txt

A chaque fois, depuis le dossier bornes-projet\bot :
  venv\Scripts\python.exe conqueror_bot.py http://IP:3000

  IP = IP du PC de demo (ipconfig sur le PC de demo -> "Adresse IPv4")

ATTENTION : mode REEL par defaut (clique vraiment dans Conqueror).
Demo sans toucher a Conqueror : taper avant de lancer
  cmd        : set SIMULATION_MODE=true
  PowerShell : $env:SIMULATION_MODE="true"

OK si le bot affiche "[bot] connecte a http://IP:3000".
Sinon : backend pas lance, mauvaise IP, ou pare-feu du PC de demo (port 3000).
Arreter : Ctrl+C
